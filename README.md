# 価格改定見積書・作成ツール (Price Quotation Tool)

得意先別のExcelデータを読み込み、別注商品やSP商品の価格改定をシミュレーションし、見積書Excelを自動生成するツールです。

## 🚀 利用方法（Web版）

本ツールはWebブラウザから直接ご利用いただけます。

**[Web版ツールを開く]**
> ※ここにデプロイ済みのURLを追記してください

詳細な使い方は **[利用マニュアル (MANUAL.md)](./MANUAL.md)** をご覧ください。

## ✨ 主な機能
- **自動計算**: 全商品の単価を％または一律金額で値上げシミュレーション。
- **別注グループ管理**: 材質・重量・色数が同じ商品を自動でグループ化し、一括で単価設定。
- **営Gインパクト算出**: 単価の変化に伴う営業利益（営G）の変化を自動計算。
- **インライン編集**: 各行ごとに改定単価や営Gを個別に微調整。
- **Excel出力**: そのまま得意先に提出可能な形式の見積書を自動生成。
- **セキュリティ**: データはブラウザ内でのみ処理されるため、サーバーにアップロードされず安全です。

## 🛠 開発者向けセットアップ

ローカル環境や独自のサーバーで実行する場合の詳細な手順です。

### 動作環境
- **Node.js**: v18.17.0 以上推奨
- **npm**: v9.0.0 以上

### セットアップ手順
1.  **リポジトリのクローン**:
    ```bash
    git clone https://github.com/mikami-yuji/price-quotation-tool.git
    cd price-quotation-tool
    ```
2.  **依存パッケージのインストール**:
    ```bash
    npm install
    ```
3.  **開発サーバーの起動**:
    `起動.bat` をダブルクリック、または以下のコマンドを実行してください。
    ```bash
    npm run dev
    ```
4.  **ブラウザで開く**: [http://localhost:3000](http://localhost:3000) にアクセス。

### 📦 マスターデータの管理
シミュレーションの精度を保つため、以下のマスターファイルをルートディレクトリに配置してください。
- `sp_master.xlsx`: SP商品（規格袋）の単価表。
- `search_master.xlsx`: 別注商品の価格マトリクス（材質・重量ベース）。

### 🧪 テスト・品質管理
- **ユニットテスト**: `npm test` で全15件のロジック検証が実行されます。
- **Lintチェック**: `npm run lint` でコードスタイルを確認します。
- **ビルド検証**: `npm run build` で本番環境向けのコンパイルが可能か確認します。
- **CI/CD**: GitHub Actions により、全てのプルリクエストとプッシュ時に自動的に Lint とテストが実行されます。

### ⚠️ トラブルシューティング
- **ビルドエラー**: 型定義（`src/types/index.ts`）に新しいフィールドが追加された際は、`calculator.ts` 等の戻り値と整合しているか確認してください。
- **ハイドレーションエラー**: ブラウザ拡張機能の影響で発生することがありますが、基本的には無視して問題ありません。
